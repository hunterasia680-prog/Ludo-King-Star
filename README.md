# Ludo King Star

Android wrapper project for the Ludo King Star game.

## Build a free test APK

1. Open the **Actions** tab in this repository.
2. Select **Build Ludo King Star APK**.
3. Press **Run workflow** and confirm.
4. Wait for the workflow to finish successfully.
5. Open the completed run and download the **Ludo-King-Star-APK** artifact.
6. Extract the downloaded ZIP and install `app-debug.apk` on your Android phone.

The APK is a debug/test build, not a Play Store release.

## Game modes

- Local pass-and-play: implemented in the bundled game.
- Computer opponent: implemented in the bundled game.
- Online multiplayer: the menu is a placeholder; a realtime backend (such as Firebase or Supabase) still needs to be configured before online matches work.
